# MasterGo 设计稿还原

v1.0.0 · Codex 技能

将有权复刻的设计截图按指定尺寸还原为 MasterGo 分层画板。版式、文本、卡片、按钮、图标和插画可分别编辑或替换。

## 安装

将本目录作为 `ai-design-reconstruction` 文件夹放入 `~/.codex/skills/`。确认 `SKILL.md` 位于该文件夹根目录，然后启动新的 Codex 对话。需要已连接的 MasterGo 工具和目标文件的编辑权限。

## 使用

上传截图，提供 MasterGo 文件链接和目标尺寸。只指定宽度时按截图比例计算高度。指定宽高时按目标尺寸适配版式。

> $ai-design-reconstruction 请把这张已授权复刻的截图还原到指定 MasterGo 文件。画板宽 393 px，高度按截图比例计算。

技能默认新增画板。中文使用苹方，数字使用 MiSans Latin。普通图标从字节跳动官方 IconPark 选取，复杂插画用 GPT Image 2 重绘。同步后以真实画布截图做三轮检查与修复，依次核对结构、间距及背景，字体与组件细节，以及整页回归。交付包含画板链接、尺寸及尚存偏差。

字体能否直接使用取决于当前 MasterGo 导入与编辑连接。若导入清单缺失但编辑器能应用指定字体，可先在画板中设置代表性文字层，再回读字体与字重并验证增量替换。截图只能用于估算源码中不可见的字号、字重和间距。指定模型不可用或 MasterGo 要求确认后才能截图时，技能会报告当前状态。
